# Cybersecurity-OSINT-Network-Discovery
Hands-on cybersecurity project covering OSINT with theHarvester and network discovery using Zenmap/Nmap.
Cybersecurity Project – OSINT & Network Discovery

Project Overview

This repository contains my hands-on cybersecurity practical work focused on Open-Source Intelligence (OSINT) and Network Discovery using theHarvester and Zenmap (Nmap).

The project helped me understand the fundamentals of information gathering, passive reconnaissance, network scanning, host discovery, and network topology.

Objectives

- Understand the fundamentals of Open-Source Intelligence (OSINT).
- Practise gathering publicly available domain-related information.
- Learn basic reconnaissance techniques.
- Discover active hosts on a local lab network.
- Understand network scanning results.
- Create an anonymised network topology diagram.

Tools Used

1. theHarvester – OSINT

Purpose: Information gathering and passive reconnaissance.

Practical activities:

- Explored publicly available information associated with a domain.
- Practised domain and subdomain information gathering.
- Observed discovered hostnames and IP-related information.
- Explored how OSINT tools support reconnaissance.

2. Zenmap / Nmap – Network Discovery

Purpose: Network scanning and host discovery.

Practical activities:

- Performed a local network discovery scan.
- Used the Nmap ping-scan technique.
- Identified 8 active hosts in the scanned lab network.
- Observed and interpreted scan results.
- Created an anonymised network topology diagram.

Example command used:

nmap -sn 192.168.1.0/24
